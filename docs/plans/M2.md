# M2: localized findings and input adapters

Roadmap row M2. Branch `m2-schema-adapters`, one PR.

## Goal
Every Finding points at a turn, and memdiag reads the log formats people already have. All changes add to
the current types; existing JSON keys and tests keep working.

## Changes
1. **Schema** (`memdiag/schema.py`)
   - `Event` gets an optional `memory` list (the memory context injected into this call: `{id, text}`),
     separate from `retrieved`, which holds RAG documents.
   - `Fact` gets `index`, the event index of the user message it came from.
   - `Finding` gets the localization fields from `docs/STABILITY.md`: `failing_turn`, `evidence_turns`,
     `failing_quote`, `evidence_quote`, `detector`, `detector_version`, `confidence`, `covariates`.
     A `type` property maps the legacy `category` to the stable type (`stale_memory` to `STALE_FACT`, and so on).
     `to_dict` emits the new keys alongside the old ones.
2. **Detectors** (`memdiag/detect.py`) fill those fields:
   - `failing_quote` is the sentence of the assistant turn that holds the value.
   - `evidence_quote` is the user's message for that fact.
   - Both must be verbatim substrings of their turns, enforced by a test.
   - `covariates` holds `turn_distance` and `context_tokens`.
   - The re-ask dedupe in `metrics.py` keys on `failing_turn`, which fixes the same-timestamp undercount.
3. **Adapters** (`memdiag/adapters.py`, stdlib only)
   - `events`: today's JSONL.
   - `openai`: one conversation per line, `{"messages": [{role, content}], "user_id"?, "session_id"?, "ts"?}`.
     Timestamps are synthesized in order when missing.
   - `longmemeval`: one LongMemEval item, or a list of them. Haystack sessions become events dated with
     `haystack_dates`, and the question becomes the final user turn.
   - `load(path, fmt="auto")` detects the format from the first record.
4. **CLI**: `memdiag diagnose --format {auto,events,openai,longmemeval}`.
5. **Docs**: README input formats, the STABILITY input fields, CHANGELOG.

## Tests (no network)
- Fixtures in `tests/fixtures/`: a hand-written OpenAI-messages file and a tiny LongMemEval-shaped item.
  These are made up, not real data.
- Every demo finding has `failing_turn`, `detector_version`, and verbatim quotes.
- Adapters round-trip their fixtures, and auto-detect picks the right format.
- `recall_continuity` counts two re-ask turns that share a timestamp as two failures.

## Out of scope
LLM extraction (M4), the judge layer (M3), new detectors (M5), OTel ingest (M8).
