# M3: judge layer

Roadmap row M3. Branch `m3-judge-layer`, one PR.

## Goal
One stdlib-only way to call a model. It is cached, versioned, accounted for, and fakeable, so M4 (extraction)
and M5 (detectors) never touch HTTP directly, and validation runs can be reproduced.

## Changes
1. **`memdiag/prompts/`** holds plain-text prompt files.
   - Each file has a header (`id: ...`, `version: N`) and then `---`.
   - The template body uses `string.Template` placeholders (`$query`), so JSON examples need no escaping.
   - `load_prompt(id)` returns a `Prompt` with `id`, `version` and `render(**fields)`.
   - Prompts ship as package data. The first prompt is `extract_facts` v1 (M4 uses it), carried over from
     the walkthrough with key normalization guidance.
2. **`memdiag/judge.py`**
   - `JudgeResult`: `text`, `data` (parsed JSON or `None`), `cached`, `seconds`, `model`, `prompt_id`,
     `prompt_version`.
   - `Judge` base: `ask(prompt, role, json=False, **fields) -> JudgeResult`. It handles the cache, parses JSON
     with one retry that appends the parse error, and records usage per role. Subclasses implement `_complete`.
   - `OpenAICompatJudge(base_url, model, api_key)` posts to `/chat/completions` with temperature 0 and seed 0.
     The key comes from `MEMDIAG_API_KEY` or `OPENAI_API_KEY` and is never logged. The default endpoint is
     Ollama at `http://localhost:11434/v1`. A connection error names the endpoint and tells the user how to
     start Ollama.
   - `FakeJudge(responses)` returns scripted text by prompt id, or the result of a callable. It records every call.
   - `DiskCache(dir)` keys on the sha256 of (model, prompt id and version, rendered prompt, json flag), and writes
     one JSON file per key. Files are written atomically.
   - `Usage` holds calls, cache hits, seconds and tokens per role. `usage.summary()` returns them as text.
   - `same_family(a, b)` gives a model-family check (qwen, llama, gpt, claude, gemini, mistral, phi, gemma,
     deepseek), backing the D9 warning.
3. **Packaging**: `pyproject.toml` ships `memdiag/prompts/*.txt`.

## Tests (no network, no live model)
- Prompts: the header is parsed, the version is an int, rendering works, and a missing field raises.
- `FakeJudge`: scripted and callable responses, JSON parsing, one retry on bad JSON, then `data=None`.
- `DiskCache`: a second identical call makes zero `_complete` calls. Changing the prompt version or the model
  misses the cache.
- `OpenAICompatJudge` against a local `http.server` fake in a thread checks the request body (model,
  temperature, seed, `response_format` for JSON), the auth header, token usage, and the error message when
  nothing is listening.
- `same_family`.
- A built wheel contains `memdiag/prompts/extract_facts.txt` (a CI check in the build job).

## Out of scope
Using the judge in detectors (M4/M5), an Anthropic-native adapter (optional, later), and budget stops in USD.
Calls and seconds are tracked for now, because local models have no price.
