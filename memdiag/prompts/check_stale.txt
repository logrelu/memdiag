id: check_stale
version: 2
description: Does an assistant reply present a since-updated value as the user's current situation, or as past history?
---
The user told an assistant one thing, and later updated it.

Earlier the user said: "$old_quote" (so $key was: $old)
Later the user said: "$new_quote" (so $key is now: $new)

Here is a later reply from the assistant:
"""
$reply
"""

The reply mentions "$old". How does it present "$old"?
- "current": as the user's situation now, as if the update never happened (for example "as a $old resident, ...").
- "past": as something that used to be true (for example "you used to be at $old").
- "not_about_user": not about the user at all (it names $old for some other reason).

Return JSON: {"presents_as": "current" or "past" or "not_about_user", "quote": "<the exact words from the reply that mention $old>"}
